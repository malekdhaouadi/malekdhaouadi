## Featured Projects

### Credit Risk Scoring with Explainable AI
> Python · XGBoost · scikit-learn · SHAP · SMOTE · Streamlit · Monte-Carlo

End-to-end credit default prediction on the Home Credit dataset (300,000+ applications), following the CRISP-DM methodology. Aggregated six relational tables into 41 features, rebalanced the classes with SMOTE, and compared Logistic Regression, Random Forest, and XGBoost (AUC 0.78 for the selected model). Added SHAP global and local explanations and an interactive Streamlit dashboard for credit decision support.

[View repository](https://github.com/malekdhaouadi/credit-risk-scoring)

---

### FinPulse: Real-Time Financial Dashboard & Options Pricing Engine
> React · TypeScript · FastAPI · WebSocket · NumPy · SciPy · Plotly

Multi-market dashboard (US, Tunisia, Europe, crypto, forex) with live prices, OHLCV charts, technical indicators (MA20/50, RSI14), and portfolio P&L tracking. Quantitative pricing module with Black-Scholes and Greeks, Newton-Raphson implied volatility, a Crank-Nicolson PDE solver, and FFT-based option chain pricing (Carr-Madan).

---

### MicroSure: Fintech Inclusion Platform
> Angular 18 · Spring Boot · MySQL · Redis · LLM (Groq/LLaMA) · Docker

Full-stack microfinance platform with 7 modules, including digital savings groups, parametric insurance, an agentic AI advisor, and an analytics dashboard. Financial logic covers EMI computation, actuarial scoring, and Monte-Carlo portfolio simulation. Fraud detection and risk scoring use SVM, Random Forest, XGBoost, and Isolation Forest.

---

### Palm Vein Biometric Recognition System
> Python · PyTorch · ResNet18 · OpenCV · scikit-learn

Deep learning pipeline for identity authentication based on palm vein patterns. Transfer learning with ResNet18 pre-trained on ImageNet, fine-tuned on 1,200 images from 50 individuals. Compared against classical baselines (SVM, Random Forest) on precision, recall, and F1-score.

---

### Information Efficiency of Financial Markets
> R · RStudio · quantmod · tidyverse · ggplot2

Comparative study of four markets (S&P 500, CAC 40, Bovespa, BIST 100) over seven years of daily data. Ran 38 OLS regressions based on the Sharpe model to test information efficiency before and after COVID-19.

---

### Physioform: Healthcare Desktop Application
> C++ · Qt · Python · Arduino · OpenCV

Clinic management application with scheduling, payments, notifications, voice processing, and a chatbot. Developed in a team using agile methodology, with an interface designed for non-technical users. Ranked in the top 10 teams of ESPRIT's annual Bal de Projet.
